# Rock-Physics-Constrained-Marine-caprock-Prediction
This repository contains MATLAB and Python code and synthetic-model data associated with the manuscript: "Physics-Constrained Intelligent Inversion and Marine Caprock Identification Driven by Rock Physics". The repository covers rock-physics modeling and validation, physics-constrained inversion of caprock-sensitive parameters and mineral composition, rock-physics-guided lithology classification, and baseline comparison methods.
